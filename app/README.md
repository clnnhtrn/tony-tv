# App (phase 4)

A native Android TV / Google TV app, to be created here as an Android Studio project.

- Kotlin, **Jetpack Compose for TV** (`androidx.tv`), **Media3 / ExoPlayer**
- `LEANBACK_LAUNCHER` + a 320×180 TV banner, so Tony appears in "Your apps"
- Cleartext HTTP allowed, because many free streams use `http://`
- Screens: Home, First-run country picker, Details, Player with preview strip, Player options, Search, Favourites and Settings. Follow `design/mockups/v5-FINAL/`.
- Install on the Chromecast with Google TV using Android Studio's **Run** button over Wi-Fi debugging.

See `CLAUDE.md` sections 5 and 7 for the full technical and design spec.

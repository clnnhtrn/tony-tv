# Tony

A clean, simple Google TV app for watching free-to-air channels from Lebanon, Australia and other countries. It's built for family members who aren't technical. "Put Tony on."

- **Start here:** [`CLAUDE.md`](CLAUDE.md) is the full brief: use case, decisions, design spec, boundaries and next steps.
- **Plan:** [`docs/PLAN.md`](docs/PLAN.md)
- **How we got here:** [`docs/CHAT_RECAP.md`](docs/CHAT_RECAP.md)
- **Design:** [`design/`](design/). The final spec is `design/mockups/v5-FINAL/`. All earlier versions are kept alongside it.
- **Channel list:** [`channels/`](channels/) (to build next)
- **Android TV app:** [`app/`](app/) (to build after the channel list)
